# Pomodoro App (Full Stack Personal Project) Built a productivity timer app using React.js frontend and Flask + SQLAlchemy backend. Implemented REST API, dynamic timer editing, and styled component system. Have it structured so that I can implement more features later on.
A full-stack productivity timer app built with **React.js** and **Flask**, featuring customizable countdowns, audio alerts, and project-based time management.

##  Features

-  Create & delete projects
-  Start/pause/reset an editable Pomodoro timer
- Audio alert when timer completes (custom sound support)
- Project and timer data stored in a SQLite database
-  Full REST API built with Flask
-  Frontend-backend integration via Axios and CORS
- Mobile-responsive, clean UI using vanilla CSS

##  Tech Stack

| Frontend      | Backend      | Database  |
|---------------|--------------|-----------|
| React.js      | Flask        | SQLite    |
| React Router  | Flask-CORS   | SQLAlchemy |
| Axios         | REST API     |           |
